# 數應記憶實驗室

140 張《數位科技應用》第 4～7 章必背重點題卡（長文件、表單與合併列印、簡報軟體、簡報編輯），每張卡只考一個記憶點，支援錯題重現、連勝鼓點、通關煙火及瀏覽器進度保存。粉紅色主題。

操作：向下鍵翻卡、向左鍵答對、向右鍵再練；亦可點擊或滑動。

題卡由 `../app47-game-build/build_cards.py` 從《數位科技應用必背重點》PDF 產生（需要 PyMuPDF）。

GitHub Pages：從 main 分支根目錄部署。

本遊戲為自主複習，學生自行核對答案；進度不是防作弊的正式成績。

錯題：答錯的卡會在 3 張後重新出現（剩不到 3 張時排到最後）。每張答錯過的卡都記入「錯題紀錄」，可按「挑戰錯題」或在任務選單選「★ 錯題再挑戰」重練；「清除紀錄」會清空錯題紀錄，不影響各任務進度。
